# Hardhat Smart Contract Journey

Repositorio de aprendizaje para Solidity, Ethereum y desarrollo de smart contracts con Hardhat.

## Modulos

- `00-fundamentos-blockchain`: conceptos base de blockchain y Ethereum.
- `01-fundamentos-solidity`: fundamentos de Solidity con contratos, documentacion, scripts, Ignition y tests.

## Primer modulo practico

Para trabajar con Solidity:

```bash
cd 01-fundamentos-solidity
npm install
npx hardhat compile
npx hardhat test
```

El curso esta organizado para avanzar desde conceptos simples hasta patrones mas completos de desarrollo Web3.
